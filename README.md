# RPi5-SmartCar-Navigation-Server

Центральний сервер навігації та обходу невідомих перешкод для кімнатної машинки на STM32F103 & ESP32.

## Архітектура системи
* **Raspberry Pi 5**: Бекенд на Flask (SSE потік для UI) + MQTT брокер Mosquitto (планування А*).
* **UI (Браузер)**: HTML5 Canvas з компасною інверсією осі Y.
* **Машинка (STM32/ESP32)**: Рівень заліза, одометрія, далекомір Sharp на сервоприводі.

## Фінальна специфікація MQTT взаємодії

Координатна система: Компасна (Північ зверху `0°`, Схід праворуч `90°`, рух за годинниковою стрілкою). Фізична карта: 8х8 метрів.

### 1. Топік: `robot/telemetry` (Робот -> RPi5)
* **Частота**: До 20 Гц (кожні 50 мс), тільки під час руху чи розвороту корпусу.
* **Формат**: JSON
```json
{
  "x": 4.35,
  "y": 2.10,
  "theta_deg": 125.5,
  "status": "moving"
}
```
* **Статуси (`status`)**: `"stopped"`, `"moving"`, `"scanning"`, `"calibrating"`, `"arrived"`.

### 2. Топік: `robot/control` (RPi5 -> Робот)
* **Формат**: JSON `{"command": "action"}`
* **Команди**: `"start"` (рух дозволено), `"stop"` (аварійне гальмо), `"calibrate"` (старт обертання для магнітометра).

### 3. Топік: `robot/path` (RPi5 -> Робот)
Передає укрупнені ключові точки зламу векторного маршруту у фізичних метрах.
* **Формат**: JSON
```json
{
  "points": [
    {"x": 4.05, "y": 4.05},
    {"x": 4.05, "y": 5.20},
    {"x": 5.80, "y": 5.20}
  ]
}
```

### 4. Топік: `robot/obstacle_scan` (Робот -> RPi5)
Надсилається строго під час зупинки по перешкоді після панорамного огляду головою Sharp від -90° до +90°.
* **Формат**: JSON
```json
{
  "angles": [-90, -45, 0, 45, 90],
  "distances": [1500, 850, 320, 410, 1500]
}
```
* **Примітки**: Відстані передаються цілими числами в міліметрах (`мм`).
